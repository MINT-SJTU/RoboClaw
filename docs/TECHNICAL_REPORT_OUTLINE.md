# RoboClaw 技术报告整体逻辑
## 1. 引言

### 1.1 研究背景

近年来，大语言模型在自然语言理解、复杂推理、代码生成和多轮交互等方面表现出较强的通用能力。随着函数调用、工具使用、任务规划和外部环境反馈等机制的发展，LLM 不再只是一个生成文本的对话模型，而逐渐成为能够参与复杂任务执行的 Agent。这样的变化使模型可以在数字环境中调用搜索、文件、代码、网页或外部 API 等工具，从而把语言理解能力延伸到实际工作流程中。由此产生的 Agent 系统，正在软件开发、知识管理、自动化办公和数据分析等场景中展现出新的提效潜力。

与此并行，具身智能也在快速发展。具身智能关注智能体如何在真实或模拟的物理环境中感知、理解并采取行动，其目标不只是让机器人完成预设程序，而是希望机器人能够理解人类的自然语言指令，并在环境中完成具有一定泛化能力的短程或长程任务。近年来，视觉-语言-动作模型、世界模型以及面向机器人控制的多模态基础模型不断出现，推动机器人从传统的任务脚本和专用控制器，逐渐走向由语义理解、视觉感知和动作生成共同支撑的新范式。

然而，具身智能与普通语言模型所面对的问题并不相同。LLM 主要操作文本、代码、网页和 API 等数字对象，而具身智能天然需要与物理实体交互。机器人任务发生在具有空间结构和物理约束的环境中，动作会改变物体状态，执行结果也会通过视觉、力觉或其他物理反馈重新影响后续决策。同时，不同机器人在本体结构、自由度、末端执行器和可操作对象上存在显著差异，这使得具身智能系统必须同时考虑语义理解、空间关系、动作可达性和硬件适配等问题。因此，将 Agent 思想引入具身智能，并不是为机器人简单增加一个对话入口，而是在具身基础模型之上，进一步组织任务意图、环境反馈和外部能力，使机器人能够面向更完整的物理世界任务进行持续决策与执行。

在这样的背景下，一个自然的问题开始浮现：当具身智能基础模型的推理能力不断增强时，是否也需要一种面向物理世界的 Agent 化系统形态，来帮助模型组织上下文、理解任务意图、连接外部工具，并在真实机器人工作流中形成可持续的执行闭环。这个问题构成了本文讨论 RoboClaw 系统的基本出发点。

### 1.3 报告组织

本文以 RoboClaw 为对象，讨论如何将具身任务从自然语言目标转化为可组织、可执行、可追踪的系统过程。报告的重点不是提出单一模型，而是说明 RoboClaw 如何将模型推理、物理实体适配、数据管理和策略迭代组织到统一的具身智能系统中。

第 2 章给出系统总览，首先说明 RoboClaw 的系统定位，再从 Embodied Main Agent、Long-Horizon Task Memory Sub-Agent、Data Lifecycle Sub-Agent、Embodiment Adaptation Sub-Agent 和 Scalable Skill and Tool Layer 等部分概括整体架构。随后，本章会整理系统支持的核心工作流，并给出后续章节的阅读地图。

第 3 章介绍 Embodied Main Agent，重点说明主 Agent 如何进行任务目标解析、阶段划分、子 Agent 调度、执行状态汇总和全局上下文构造。

第 4 章介绍 Long-Horizon Task Memory Sub-Agent，重点说明系统如何维护历史长程任务、当前子任务进展、阶段性结果和用户交互偏好。

第 5 章介绍 Data Lifecycle Sub-Agent，重点说明数据采集、dataset 版本管理、数据操作和训练周期数据管理等能力。

第 6 章介绍 Embodiment Adaptation Sub-Agent，重点说明系统如何管理物理实体、监视硬件健康状态，并将具体任务适配到不同机器人链路中。

第 7 章介绍 Scalable Skill and Tool Layer，重点说明系统如何将基础工具、机器人工具、外部服务和用户自定义能力封装为可调用的工具与 skill。

## 2. 系统总览

RoboClaw 是一个开源具身智能助手系统，面向真实机器人操作、数据闭环和 LLM Agent 交互。它不是单一控制器，而是一个将机器人工作流和 AI 助手能力结合起来的系统框架。
本章作为全局地图，概括 RoboClaw 的系统定位、模块关系和核心工作流。

从整体结构上看，RoboClaw 可以被理解为一个以 Embodied Main Agent 为核心的主-子 Agent 协同系统。外部请求通过 CLI、Web 或 IM 等入口进入运行时，随后由主 Agent 维护全局任务视图，并根据任务类型调度不同的子 Agent 与工具能力。

- Embodied Main Agent：负责子 Agent 调度与协同、任务目标解析与阶段划分、执行状态汇总与下一步决策，以及全局上下文构造。
- Long-Horizon Task Memory Sub-Agent：负责历史长程任务与阶段性结果索引、当前任务拆解与子任务进展维护，以及用户意图与交互风格维护。
- Data Lifecycle Sub-Agent：负责数据采集与 dataset 版本管理、数据质量检查与清洗筛选标注，以及训练记录和推理结果回流等训练周期数据管理。
- Embodiment Adaptation Sub-Agent：负责硬件资源管理、硬件自检与健康监视，以及遥操作、回放、策略推理等任务在具体硬件上的链路适配。
- Scalable Skill and Tool Layer：负责将文件、shell、web、机器人操作、Hub 同步和用户自定义能力封装为可调用的工具或 skill。

这些部分之间形成一个简洁的执行关系：Embodied Main Agent 负责组织任务和协调子 Agent；各子 Agent 围绕记忆、数据和物理实体适配提供领域判断；Skill and Tool Layer 将这些判断转化为具体执行动作；执行结果再回到任务上下文中，支持下一轮规划和决策。
